OnCollision trigger — fires when another entity moves into the same cell (natural extension of the current Eat/Swap logic)
Timer trigger — "fire if more than N ticks or seconds have passed" — enables cooldowns on abilities, (use calculated ticks per second (tps))
InRange condition — "is there an entity of type X within radius N?" — sensor-style detection without moving
BroadcastEvent + OnEvent trigger — entity A fires an event by name; all entity Bs with OnEvent rules react (pub/sub between entities)
SetColor action — dynamically change an entity's color based on state (e.g., health bar encoded in color)
Teleport action — instantly move to a random empty cell, or to the nearest cell of a given type
